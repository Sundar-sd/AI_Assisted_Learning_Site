## 🎯 Overview

AI Assisted Learning Site is an innovative educational platform that combines modern web technologies with artificial intelligence to provide personalized learning experiences. The application features an intuitive user interface and a robust backend infrastructure designed to support dynamic AI-powered educational content.

## ✨ Features

- **AI-Powered Learning**: Intelligent system for personalized educational content
- **Responsive Design**: Fully responsive user interface for seamless experience across devices
- **Modern Architecture**: Separation of concerns with dedicated Frontend and Backend
- **Real-time Interactions**: Dynamic content delivery powered by the backend API
- **User-Friendly Interface**: Intuitive design focused on educational engagement

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v14.0.0 or higher)
- **npm** (v6.0.0 or higher) or **yarn**
- **Git** (for version control)

## 🚀 Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/Sundar-sd/AI_Assisted_Learning_Site.git
cd AI_Assisted_Learning_Site
```

### Step 2: Install Backend Dependencies

```bash
cd Backend
npm install
cd ..
```

### Step 3: Install Frontend Dependencies

```bash
cd Frontend
npm install
cd ..
```

## ⚙️ Configuration

1. Create a `.env` file in the `Backend` directory with the necessary environment variables:

```env
PORT=5000
NODE_ENV=development
# Add other configuration variables as needed
```

2. Update any API endpoints in the Frontend configuration to match your backend server URL.

## 🎮 Running the Application

### Start the Backend Server

```bash
cd Backend
npm start
# Backend runs on http://localhost:5000
```

### Start the Frontend Development Server

In a new terminal:

```bash
cd Frontend
npm start
# Frontend runs on http://localhost:3000
```

## 💡 Usage

1. Open your browser and navigate to `http://localhost:3000`
2. Explore the AI-assisted learning features
3. Interact with the application to experience personalized learning
